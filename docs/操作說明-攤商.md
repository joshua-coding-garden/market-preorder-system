# 攤商操作說明

從綁定帳號到現場核銷，一頁看完。

---

## 第一次使用：綁定你的攤位

主辦單位會給你一組**邀請碼**，長得像 `A20260912-0001`。

兩種綁定方式，擇一即可：

1. **在 LINE 直接輸入**（最快）
   加市集官方帳號好友，然後傳一則訊息：
   ```
   邀請碼 A20260912-0001
   ```
   綁定成功會回覆你的攤商名稱與攤位號。

2. **在網頁輸入**
   LINE 選單點「攤商專區」→「輸入邀請碼」→ 貼上送出。

> ⚠️ **一組邀請碼只能用一次。** 如果你的攤位要讓兩個人都能操作（例如老闆跟工讀生），
> 請跟主辦單位說，他們會再發一組新的給第二個人。
>
> 邀請碼在**市集當天結束後就會失效**，下一場會拿到新的。

## 上架商品

### 建立商品（只要做一次，之後每場沿用）

「攤商專區」→ 最下方「商品管理」→「新增商品」：

| 欄位 | 說明 |
|---|---|
| 商品代碼 | 你自己認得就好，例如 `CR01`。同一攤不能重複 |
| 商品名稱 | 顧客看到的名字 |
| 基本價 | 平常的售價。每一場可以個別調整 |
| 說明 | 選填 |
| 圖片 | 選填，但**有圖的商品賣得比較好**。手機直接拍就可以，系統會自動壓縮 |

**內容物**是顧客可以加購的選項，例如可頌的「加起司 +10」：

- 每一項可以設加價（不加價就填 0）
- 勾「允許特製備註」的話，顧客可以打字，例如「不要太焦」
- 可以用 ↑ ↓ 調順序

> 商品是跨場次共用的，不用每場重建。

### 每一場的上架設定

「攤商專區」→ 點該場次 →「本場上架」：

1. 勾選這次要賣的商品
2. 設定**本場售價**（預設帶入基本價，可以改）
3. 設定**預購上限** —— 這場最多接幾份。留空代表不限
4. 狀態選「販售中」或「已售完」

按「儲存上架設定」。

> 懶得重設？按右上角「**沿用上一場**」，會把上一場的品項、價格、上限整組複製過來。
> 已經設好的不會被覆蓋。

**沒勾選的商品這場就不會出現。**

## 市集當天

「攤商專區」→ 點該場次，會看到四個按鈕：

### 訂單

所有向你預購的訂單，依狀態分頁（待取貨／已取貨／未取／取消）。

**新訂單會自動跳出來，不用一直重新整理。** 右上角會顯示連線狀態；
就算網路斷了，系統每分鐘也會自己補抓一次。

點進單筆可以看到顧客姓名、電話（點一下可以直接撥）、取貨時間、完整明細與特製備註。

### 備貨總表

這場**總共要準備多少**，一眼看完。

- 上面那層是商品總數（例如「可頌 12」）
- 點一下展開，會看到內容物的數量（例如「加起司 5」）

只算「待取貨」和「已取貨」的訂單，被標記為未取或取消的不算。

### 核銷（現場用這個）

顧客來的時候：

1. 請他出示 **4 碼取貨碼**
2. 在四個大格子裡輸入（會自動跳格、自動轉大寫）
3. 輸入完會自動查詢，跳出訂單內容與**應收金額**
4. **收錢、給東西**
5. 按「確認取貨」

這頁字特別大、按鈕特別大，就是為了戶外站著操作。

> **查無此取貨碼？** 確認一下顧客是不是拿錯攤位的碼 —— 每一攤的碼都不一樣。

如果顧客沒出現，到「訂單」點進該筆按「未取」。

## 想發推播給顧客？

「攤商專區」→ 該攤商 →「推播申請」。

兩種方式：

- **自己寫文案** → 填標題和內容，送出後等主辦單位審核
- **請廠商代寫** → 只要送出申請，主辦單位會幫你寫

送出後在列表看得到狀態。**被退回的話會顯示原因**，改一改再送一次。

> 推播是花錢的（LINE 官方帳號每月有訊息額度），所以一律要經過主辦單位核准才會發出去。

## 常見問題

**我看得到別攤的訂單嗎？**
看不到。系統只會給你自己攤位的資料。

**改了商品價格，之前的訂單會變嗎？**
不會。訂單成立的當下就把價格記下來了，之後怎麼改都不影響已成立的訂單。

**市集結束後還能改訂單嗎？**
主辦單位「結案」之後就不能了，所有資料變成唯讀。結案時還沒取貨的會自動變成「未取」。

**我有兩個攤位怎麼辦？**
兩個攤位各自的邀請碼都綁定到同一個 LINE 帳號就好，攤商專區上方會出現切換按鈕。
